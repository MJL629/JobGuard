# JobGuard（求职卫士）— 产品需求文档 V1.0

> 面向求职者的多智能体岗位筛选与简历优化系统

---

## 一、产品概述

### 1.1 产品定位

**JobGuard** 是一款面向计算机方向应届生及 1-2 年职场新人的智能求职助手。核心解决两大痛点：

1. **避雷**：帮助用户识别垃圾岗位、虚假宣传、高风险企业，避免踩坑
2. **精准投递**：根据目标岗位自动筛选用户项目经历、改写简历描述、生成针对性简历和招呼语

### 1.2 目标用户画像

| 维度 | 描述 |
|------|------|
| 人群 | 计算机相关专业应届毕业生 + 1-2 年职场新人 |
| 学历 | 本科为主 |
| 痛点一 | 有多个项目经历但不知道针对不同岗位如何筛选和排序 |
| 痛点二 | 无法判断岗位是否为垃圾岗位、虚假宣传、刷 KPI |
| 痛点三 | 简历不会包装，不同岗位用同一份简历海投 |
| 技能水平 | 有基础编程能力，但对职场信息不对称 |

### 1.3 核心价值主张

> **"终于可以筛选出适合我的岗位（不是骗人的），而且能自动帮我生成简历和招呼语，太智能了。"**

## 二、MVP 功能范围

### 2.1 第一版包含功能

#### 模块一：用户画像构建（入口模块）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 上传简历 | 用户上传现有简历（PDF/Word/图片），系统提取结构化信息 | P0 |
| 对话补充 | 通过多轮对话收集：项目经历、技能、教育背景、期望薪资、工作地点、工作强度偏好（单休/双休/加班接受度） | P0 |
| 画像存储 | 所有信息存入用户知识库（RAG），支持后续检索和更新 | P0 |

#### 模块二：岗位解析与分析（避雷模块）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 链接解析 | 用户粘贴招聘平台链接（BOSS直聘、拉勾等），系统提取岗位结构化信息 | P0 |
| 截图解析 | 用户上传岗位截图，系统 OCR + LLM 提取信息 | P1 |
| 企业背调 | 实时检索：社保人数、劳动争议、工商风险、网络口碑（脉脉/看准网/知乎/小红书/抖音/高德地图） | P0 |
| 薪资真实性分析 | 对比 JD 薪资范围与同公司/同岗位网络爆料 | P1 |
| 刷 KPI 判断 | 分析岗位发布时间、刷新频率、同一公司重复发布模式 | P1 |
| 工作制度分析 | 从 JD 文案判断加班文化（"抗压能力强""拥抱变化""弹性工作制"等话术） | P0 |
| 综合推荐指数 | 结合用户画像中的工作强度偏好，输出 1-5 星推荐指数 + 避雷说明 | P0 |

#### 模块三：岗位推荐（发现模块）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 岗位库 | 聚焦计算机方向四大类岗位，系统主动爬取并存储 | P0 |
| 岗位分类 | 工程开发类 / 算法研发类 / 产品数据测试类 / 安全类（共 14+ 细分方向） | P0 |
| 智能推荐 | 基于用户画像匹配岗位库，推荐适合的岗位列表 | P0 |

#### 模块四：简历生成（转化模块）

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 项目筛选排序 | 根据目标岗位 JD，从用户所有项目经历中选出最相关的 2-3 个，按含金量排序 | P0 |
| 项目描述改写 | 同一段经历根据岗位方向调整描述侧重点 | P0 |
| 技能关键词注入 | 根据 JD 技术要求，自然融入匹配的技能关键词 | P0 |
| 自我评价/求职意向生成 | 根据岗位和公司，生成简历开头的个人总结段落 | P0 |
| 简历模板 | 统一使用一套专业模板，不按公司文化定制 | P0 |
| 招呼语生成 | 针对岗位和公司，生成投递附言/招呼语 | P0 |
| 简历导出 | 支持 PDF 下载 | P0 |

#### 模块五：投递辅助

| 功能点 | 描述 | 优先级 |
|--------|------|--------|
| 半自动投递 | 系统生成简历 + 招呼语，用户手动复制到招聘平台投递 | P0 |

### 2.2 第一版不做

- 全自动投递（涉及账号体系、反封禁、法律风险）
- 非计算机方向岗位
- 简历模板多样化
- 企业信息预建数据库（改用实时检索）
- 定时监控/推送

## 四、多智能体架构设计

### 4.1 Agent 分工

| Agent | 触发条件 | 职责 |
|-------|----------|------|
| **用户画像 Agent** | 用户首次使用 / 主动更新信息 | 通过对话收集用户背景、项目经历、偏好（薪资/地点/工作强度等），存入用户知识库 |
| **岗位解析 Agent** | 用户发送岗位链接/截图 | 提取结构化岗位信息（JD、薪资、公司名、地点等） |
| **企业背调 Agent** | 岗位解析完成后自动触发 | 实时检索社保人数、劳动争议、工商信息、网络口碑，生成企业风险评估报告 |
| **岗位匹配 Agent** | 用户请求推荐 / 分析岗位时 | 结合用户画像和岗位信息，计算匹配度，给出投递建议 |
| **简历生成 Agent** | 用户确认投递某岗位后 | 筛选项目、改写描述、注入关键词、生成自我评价、生成简历 + 招呼语 |
| **调度与自检 Agent** | 贯穿全局 | 管理多个 Agent 的执行顺序、数据流转、冲突仲裁、结果一致性审查 |

### 4.2 Agent 调度规则

```
用户意图识别 → 路由到对应流程：

意图 = "分析岗位/避雷"
  → 岗位解析 Agent → 企业背调 Agent → 岗位匹配 Agent → 输出分析报告

意图 = "生成简历"
  → 岗位解析 Agent（如未解析）→ 简历生成 Agent → 输出简历 + 招呼语

意图 = "推荐岗位"
  → 岗位匹配 Agent（检索岗位库）→ 输出推荐列表

意图 = "补充信息/更新画像"
  → 用户画像 Agent → 更新知识库
```

### 4.3 数据优先级规则

```
用户上传的岗位信息 > 实时检索结果 > RAG 知识库历史数据

当实时检索与知识库冲突时 → 优先采信实时检索结果
当用户提供的信息与检索结果冲突时 → 优先采信用户提供的信息
```

## 五、RAG 知识库设计

### 5.1 存储内容

| 知识库 | 存储内容 | 检索场景 |
|--------|----------|----------|
| **用户知识库** | 简历信息、完整项目经历、技能、教育背景、偏好（薪资/地点/强度） | 生成简历时检索匹配项目；匹配岗位时检索技能要求 |
| **企业/岗位知识库** | 历史分析过的岗位、企业信息、风险评估结果、网络口碑摘要 | 复用分析结果；构建企业画像；避免重复分析 |
| **简历范例知识库** | 优质简历范例、不同岗位类型的项目描述改写模式、技能关键词库 | 提升简历生成质量；提供改写参考 |

### 5.2 检索策略

- **用户知识库**：按用户 ID 隔离，检索用户的所有相关信息
- **企业知识库**：按企业名 + 岗位名检索，命中后对比实时检索结果
- **简历范例库**：按岗位类型检索相似简历范例

| 组件 | 技术选型 |
|------|----------|
| 语言 | Python 3.11+ |

## 七、核心用户流程

### 7.1 新用户引导流程

```
1. 用户进入系统
2. 对话 Agent 引导：询问求职方向、期望薪资、工作地点、工作强度偏好
3. 用户上传现有简历（可选）
4. 对话 Agent 追问项目经历、技能细节
5. 用户画像构建完成 → 存入用户知识库
6. 自动跳转岗位推荐页
```

### 7.2 岗位分析流程（避雷）

```
1. 用户粘贴岗位链接 / 上传截图
2. 岗位解析 Agent 提取结构化信息
3. 企业背调 Agent 实时检索：
   - 社保人数（天眼查/企查查）
   - 劳动争议（裁判文书网/天眼查）
   - 网络口碑（脉脉/看准网/知乎/小红书/抖音/高德）
   - JD 话术分析（加班文化判断）
4. 岗位匹配 Agent 结合用户画像计算匹配度
5. 输出分析报告：
   - 综合推荐指数（1-5 星）
   - 薪资真实性评估
   - 企业风险提示
   - 工作制度分析
   - 匹配度评分
   - 投递建议
```

### 7.3 简历生成流程

```
1. 用户选择目标岗位（从推荐列表或分析结果中）
2. 简历生成 Agent 从用户知识库检索所有项目经历
3. 根据岗位 JD 筛选最相关的 2-3 个项目
4. 按含金量排序
5. 针对每个项目，根据岗位方向改写描述侧重点
6. 注入匹配的技能关键词
7. 生成自我评价/求职意向段落
8. 组装完整简历 + 生成招呼语
9. 展示预览 → 用户确认 → 下载 PDF
```

## 八、岗位分析维度详表

| 分析维度 | 数据来源 | 输出内容 |
|----------|----------|----------|
| 社保人数 | 天眼查/企查查/爱企查 | 参保人数、变化趋势、是否存在大规模减员 |
| 劳动争议 | 中国裁判文书网/天眼查司法风险 | 劳动仲裁数量、类型、判决结果 |
| 工商风险 | 天眼查/企查查 | 经营异常、行政处罚、股权冻结 |
| 网络口碑 | 脉脉/看准网/知乎/小红书 | 员工评价、离职原因、公司文化 |
| 地理位置口碑 | 高德地图/抖音 | 办公环境、周边配套、实地评价 |
| 薪资真实性 | 招聘平台 + 脉脉爆料 | 薪资是否虚标、社保基数是否合规 |
| 刷 KPI 嫌疑 | 岗位发布时间/刷新频率/重复模式 | 是否为"假岗位" |
| 工作制度 | JD 文案分析 | 单双休判断、加班文化识别、法定假日安排 |
| 话术陷阱 | JD 文案语义分析 | "抗压能力强"→加班多；"拥抱变化"→业务不稳定；"弹性工作制"→无偿加班 |
