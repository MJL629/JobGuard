## 主标题

JobGuard 求职卫士

## 副标题

AI 驱动的求职避雷与定向简历 Agent

## 一句话介绍

通过深度对话和简历解析构建求职画像，结合岗位数据、企业核验来源和 LangGraph 工具工作流，为求职者提供岗位推荐、风险分析和定向简历生成。

## 痛点

- 简历无法完整表达真实项目和能力
- 岗位信息不透明，真假与风险难判断
- 岗位推荐理由重复，缺少个性化
- 企业风险来源分散，普通用户难以核验
- 大模型容易在无来源时虚构事实

## 核心能力

- 深度画像对话
- 多份简历上传与解析
- 个性化岗位推荐
- 岗位截图/链接分析
- 企业风险证据门禁
- 定向简历生成
- Agent 工具调用观测

## 技术架构

前端：Vue 3 + Vite + Element Plus  
后端：FastAPI + SQLAlchemy + MySQL  
Agent：LangGraph + MCP + LangChain  
数据：ChromaDB + 官方开放岗位数据 + 企业证据表  
观测：AgentRun + ToolTrace + Evaluation + LangSmith Adapter

## 创新点

### 证据门禁

无来源不生成企业风险数字，防止大模型虚构社保人数、仲裁数量和公司口碑。

### 求职画像联动

对话、简历和补充经历共同构建画像，服务于岗位推荐和定向简历。

### 工具化 Agent

岗位检索、企业证据、学习资源、核验计划通过 MCP 工具标准化暴露。

### 可观测工程

记录 Agent 运行、工具调用、失败步骤和耗时，便于调试与评估。
