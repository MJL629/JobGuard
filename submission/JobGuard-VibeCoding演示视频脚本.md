# JobGuard 求职卫士 - 演示视频脚本

> 视频要求：2-5 分钟  
> 建议时长：3 分 30 秒 - 4 分 30 秒  
> 建议最终命名：`【群聊】-第X组-姓名-VibeCoding演示视频.mp4`

## 录制前准备

- 后端运行：`http://127.0.0.1:8000`
- 前端运行：`http://127.0.0.1:5173` 或当前实际端口
- 打开接口文档：`http://127.0.0.1:8000/docs`
- 准备一个无隐私的测试账号
- 准备一份脱敏简历
- 准备一个目标岗位
- 准备一张岗位截图
- 准备定向简历模板

## 时间轴脚本

### 0:00 - 0:20 项目介绍

旁白：

大家好，我的项目是 JobGuard 求职卫士，这是一个面向计算机方向求职者的 AI 求职辅助系统。它不是单纯聊天机器人，而是围绕求职画像、岗位推荐、企业风险分析和定向简历生成构建的完整 Agent 应用。

画面：

- 首页或登录页
- 简要展示导航栏

### 0:20 - 0:50 登录与系统概览

旁白：

系统采用 Vue 前端和 FastAPI 后端，数据持久化到 MySQL。登录后可以进入对话助手、求职画像、岗位推荐、岗位分析、简历生成和 Agent 观测页面。

画面：

- 登录
- 进入系统
- 快速切换几个页面

### 0:50 - 1:30 深度对话构建画像

旁白：

首先是求职画像构建。系统会主动引导用户补充岗位方向、城市、薪资、技能、项目、比赛、实习、证书和工作强度偏好。对于容易误解的表达，系统会先复述确认。

演示输入：

`我想找后端开发，期望 15K-20K，广州或深圳。我可以接受偶尔正常加班，但不接受长期高强度加班。我还做过一个 JobGuard 项目，使用 Python、FastAPI 和 LangGraph。`

继续输入：

`正确。`

画面：

- AI 复述确认
- 切换到画像页查看持久化结果

### 1:30 - 2:00 上传简历并补充画像

旁白：

系统支持多份简历上传和解析。上传后会保存原文件、解析状态和结构化结果。即使解析失败，也会明确原因，不会显示假成功。

画面：

- 上传脱敏简历
- 查看简历列表
- 查看画像更新

### 2:00 - 2:35 岗位推荐

旁白：

岗位推荐来自数据库中的真实岗位数据，包括导入的官方开放岗位数据。系统会根据用户画像计算匹配度，同时展示证据覆盖率、需要确认项和硬条件冲突。证据不足时不会显示误导性的精确百分比。

画面：

- 打开 `/jobs`
- 展示岗位卡片
- 展示推荐理由

### 2:35 - 3:15 岗位分析与企业核验

旁白：

点击岗位分析后，系统会分析 JD 原文风险、招聘来源和企业核验状态。这里引入了证据门禁机制：没有可核验来源时，系统不会让大模型虚构社保人数、劳动仲裁数量或公司口碑。

画面：

- 打开岗位分析页
- 展示 JD 原文风险
- 展示可核验来源
- 展示 Agent 工具调用记录
- 展示受访问控制或未核验字段

### 3:15 - 3:50 定向简历生成

旁白：

最后是定向简历。用户选择目标岗位和模板后，系统会基于已保存画像、简历和岗位要求生成定向简历。生成过程包含事实保护，不能编造用户没有提供的经历和数字。

画面：

- 打开 `/resume`
- 选择目标岗位
- 选择模板
- 点击生成
- 展示生成历史和下载入口

### 3:50 - 4:20 Agent 可观测性与总结

旁白：

系统还提供 Agent 观测页，可以查看运行记录、工具调用、失败步骤、耗时和评估结果。这让项目不只是模型调用，而是具备工程化调试和评估能力的 Agent 系统。

画面：

- 打开 `/agent-ops`
- 展示图结构、工具列表和运行记录

结束语：

JobGuard 后续可以继续接入合规企业数据 API、后台任务队列和线上部署，进一步提升岗位数据规模和企业核验能力。
